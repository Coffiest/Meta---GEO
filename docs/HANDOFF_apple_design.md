# 引き継ぎ: apple-design でアプリ全体を Apple らしくする

2026-10-12 時点。オーナー指示「アプリのありとあらゆる部分を apple-design スキルで Apple っぽくしたい」。
**画面ごとに「監査 → 直す所の一覧 → 上から1つずつ直して出荷」** で進めている(オーナーと合意した進め方)。
デザインを触る前に `.claude/skills/apple-design/SKILL.md` と CLAUDE.md のデザインルールを読むこと。

## 画面の順番(提案済み)

1. 卓(アクションバー・ベットのスライダー・席・ポット)
2. **ホーム(ロビー) ← 作業中**
3. 下から出るシート類(料金・オファー・ブラインドの表など)。引いて閉じる・途中で戻せる・勢いで閉じる
4. 結果画面・棋譜解析
5. GEO データベース
6. メニュー・設定・管理者画面

オーナーは「ホーム画面の監査をして。反応・ばね・文字・すりガラスの観点で直すべき所を一覧にしてから、上から直して」と依頼。

## 手元での確認のしかた(ホーム)

ホームはログインが要るので、手元では仮のページと仮のサーバーで描いた。

- 仮のページ: `apps/web/src/app/dev-home/page.tsx`(`<Lobby displayName=… accessToken="x" …/>` を `<Suspense>` で包むだけ)。**コミットしない**。
- 仮のサーバー: 4999 番で `/api/lobby/stats` などに仮の JSON を返す node スクリプト。形が合わない API は 404 を返すと各部品は「データなし」で描く。
  - Stats タブは仮の stats の形が足りず `toLocaleString` で落ちた(アプリの不具合ではない。仮のデータ側の問題)。Stats を確認するなら `/api/lobby/stats` の応答の形を `Lobby.tsx` の型に合わせること。
- `NEXT_PUBLIC_SERVER_URL=http://localhost:4999 pnpm exec next dev -p 3456` で起動し、Playwright(`/opt/node-tools/node_modules/playwright-core`、ブラウザは `/opt/pw-browsers/chromium`)で 390×844 を撮る。
- 型チェックで `.next/types/app/dev-home` の古い型が残って落ちたら、そのフォルダを消す。
