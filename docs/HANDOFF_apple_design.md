# 引き継ぎ: apple-design でアプリ全体を Apple らしくする

2026-10-13 時点(本番 **v1.8.1**)。オーナー指示「アプリのありとあらゆる部分を apple-design スキルで Apple っぽくしたい」。
**画面ごとに「監査 → 直す所の一覧 → 上から1つずつ直して出荷」** で進めている(オーナーと合意した進め方)。
デザインを触る前に `.claude/skills/apple-design/SKILL.md` と CLAUDE.md のデザインルールを読むこと。

## 守ること(このシリーズで決まったオーナー指示。CLAUDE.md にも書いてある)

- **端末風の演出(`$ コマンド` を1文字ずつ打ってから見出しがバッと出る・点滅カーソル)は絶対に消さない。** テック感のテーマ。一度「待ち時間」として消しかけて取り消した。`// EYEBROW` の字間もこの演出の一部なので触らない。
- **緑の光る丸い点は使わない。**
- **版の上げ方**: 軽微は下の桁(1.8.1 → 1.8.2)、さらに細かいのは4桁目(1.8.1.1、package.json は `"1.8.1+1"`)、新機能・作り直しだけ 2桁目(1.9.0)。
- 出荷: 変更ごとに1コミット1版。CI が1回25分ほどかかるので、ここまでは数個のコミットを1つの PR に載せ、**`merge_method: "rebase"`** で main に別々のコミットとして残してきた(squash にしない)。マージ後はブランチを `git checkout -B claude/happy-fermi-a6qc8h origin/main` で揃えて force push。

## 手元での確認のしかた

ログインが要る画面は、仮のページ+仮のサーバーで描く。**仮のページはコミットしない**(終わったら消す。stop hook が未追跡ファイルで止まる)。

- 卓: `apps/web/src/app/dev-table/page.tsx` に仮の `PublicHandState` で `<PokerTable>` と `<ActionBar>` を描く(`?2d` で 2D、`?turn` で手番、`?noraise` でコール/フォールドだけ)。
- ホーム各タブ: `apps/web/src/app/dev-home/page.tsx` に `<Lobby accessToken="x" …/>`。仮のサーバー(4999 番)は `/api/lobby/stats`・`bankroll-graph`・`leaderboards`・`history` を `Lobby.tsx` の型どおりに返す。
- 起動: `NEXT_PUBLIC_SERVER_URL=http://localhost:4999 pnpm exec next dev -p 3456`。撮影は Playwright(`/opt/node-tools/node_modules/playwright-core`、ブラウザ `/opt/pw-browsers/chromium`)で 390 幅。
- 止めるときは `fuser -k 3456/tcp 4999/tcp`(`pkill -f` はシェル自身に当たって落ちるので使わない)。
- 型チェックで `.next/types/app/dev-*` の古い型が残って落ちたら、そのフォルダを消す。
- `apps/web` の vitest は `knowledgeDryRun.test.ts` の4件が手元で落ちる(この作業の前から。CI は通っている)。
