- [ ] **GitHub のリポジトリを非公開にする**(2026-10-06 追加。「いつかやる」)

  - Vercel・Fly.io のデプロイは非公開でもそのまま動く。
  - 注意: 無料プランでは非公開リポジトリの GitHub Actions は月 2,000 分まで。今の CI は1回 約15分なので、月 約60回のマージで上限に当たり、CI とデプロイが止まる。超えそうなら GitHub Pro にする。

- [ ] **Stripe のカスタマーポータルで「プランの変更」を許可する**(2026-10-07 追加。v4.147.0 からプラン変更は Stripe の確認ページで行う)
  - Stripe → 設定 → Billing → カスタマーポータル → 「サブスクリプション」→「顧客がプランを切り替えられるようにする」をオン。
  - 商品に シルバー / ゴールド / プラチナ の3つの価格を追加。日割り計算は「日割り計算して即時に請求」。
  - これがオフだと、アプリでプランを変えようとしても「いまはプランの変更を受け付けていません」と出る。
