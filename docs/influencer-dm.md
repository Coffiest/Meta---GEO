# インフルエンサーへの DM 文面(ローンチパートナー)

条件の正本は `/partner-terms`(パートナー規約)。DM では条件を約束しきらず、規約のリンクを貼る。
管理者画面の「インフルエンサーのコード」から、A(最初の DM)と D(コードを渡す文面)はワンタップでコピーできる
(`apps/web/src/components/admin/PartnerPanel.tsx`。文面を変えたらそちらも揃える)。

送るときのコツ:
- **1通目は短く**。X の DM はプレビューの1〜2行で開くかが決まる。最初の行に「誰が・何の用か」。
- **相手の投稿に1行だけ触れる**(【】の部分)。テンプレの一斉送信に見えると開かれない。
- 金額は % より **円で**書く(「1人あたり約¥2,980」)。
- 返信が無ければ **3〜4日後に1回だけ**フォロー(E)。2回目は送らない。
- 1日に送る数は数十件まで(X の DM の送りすぎはスパム判定・凍結のおそれ)。

```

## B. 最初の DM(詳しい版・アプリの中身も伝える)

フォロワーが多い人・ポーカーを教えている人向け。

```
はじめまして。ポーカーの学習アプリ「Poker ART」を個人で開発している者です。
【〇〇の解説がとても分かりやすく】いつも拝見しています。

Poker ART は、無料でトーナメントを遊びながら、
・終わったあとに全部の判断を解析して「どこが良くてどこが悪かったか」を解説
・実際のプレイデータから作った戦略データベース(GTO だけでは分からない“現実の相手の傾向”)
・偏差値と全国順位で実力が数字で出る
というアプリです(バーチャルチップ専用で、お金は賭けません)。

もしよければ、実際に触ってみて、面白いと思ったところも、イマイチだと思ったところも、そのまま率直に紹介していただけないかと思いご連絡しました。

【お渡しできるもの】
・最上位のプラチナプラン(¥1,890/月)を3ヶ月無料
・あなた専用のコード: フォロワーさんは初月30%OFFで加入できます
・コードで加入した方の最初の3ヶ月の支払いの80%をお支払いします
  (1人あたりの目安: シルバー約¥2,100 / ゴールド約¥2,980 / プラチナ約¥4,080)
・報酬は専用の明細ページで1件ずつ確認できます

条件の詳細: https://meta-geo-poker.vercel.app/partner-terms
アプリ: https://meta-geo-poker.vercel.app

紹介の形式(投稿・動画・配信)や回数の決まりはありません。

## C. 配信者・YouTuber 向けの追記(A か B の最後に足す)

```
配信で使っていただく場合、トーナメントの解析画面(終わったあとに全部の判断を振り返る画面)が特に配信向きだと思います。
視聴者さんと一緒に「この判断は良かったのか」を見られます。
```

## D. 引き受けてもらえたあと(コードを渡す)

管理者画面で「コードを発行」→ その人の行の「コードを渡す文面」でコピーできる(コードと明細 URL が入った状態になる)。

```
ありがとうございます!専用のコードをお送りします。

コード: 〈コード〉
(有料プランの決済画面で「プロモーションコードを追加」に入力すると、初月の支払いが30%OFFになります)

報酬の明細(あなた専用のページです。他の方には共有しないでください):
〈明細 URL〉
条件: https://meta-geo-poker.vercel.app/partner-terms

お願いが2つだけあります。
・投稿には「#PR」など、広告であることが分かる表示を必ず入れてください(ステマ規制のため)
・アプリに登録したアカウントの表示名を教えてください。プラチナプランをこちらで付与します

ほかは自由です。率直な感想をそのまま書いていただいて大丈夫です。
```

## E. 返信が無いとき(3〜4日後に1回だけ)

```
先日ご連絡した Poker ART の者です。お忙しいところ失礼します。
もしご興味がなければ、このままスルーしていただいて大丈夫です。
プラチナプランだけでも試していただけるなら、すぐにお渡しします。
```

## F. 断られたとき

```
お返事ありがとうございます!承知しました。
もし今後気が向いたら、いつでもお声がけください。
```

## G. 報酬の振込先を聞く(最初の振込の前月末ごろ)

```
いつもありがとうございます。〈月〉分の報酬が ¥〈金額〉 になりましたので、月末にお振り込みします。
振込先(銀行名・支店名・口座種別・口座番号・口座名義)を教えていただけますか。
明細: 〈明細 URL〉
```

---

## 書かないこと

- 「必ず勝てる」「稼げる」などの断定(規約で禁止している表現。景品表示法の優良誤認にもなる)。
- 条件を DM の文面だけで約束しない。必ず規約のリンクを添える(規約を変えたら DM の文面も揃える)。
