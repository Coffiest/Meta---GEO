# インフルエンサーへの DM 文面(ローンチパートナー)

条件の正本は `/partner-terms`(パートナー規約)。DM では条件を約束しきらず、規約のリンクを貼る。
管理者画面の「インフルエンサーのコード」から、A(最初の DM)と D(コードを渡す文面)はワンタップでコピーできる
(`apps/web/src/components/admin/PartnerPanel.tsx`。文面を変えたらそちらも揃える)。

送るときのコツ:
- **1通目は短く**。X の DM はプレビューの1〜2行で開くかが決まる。最初の行に「誰が・何の用か」。
- **相手の投稿に1行だけ触れる**(【】の部分)。テンプレの一斉送信に見えると開かれない。
- 金額は % より **円で**書く(「1人あたり約¥2,980」)。報酬は計算の手順と例まで書く(あいまいだと怪しまれる)。
- **誰が送っているか**を最初の1文で(九工大・福岡の学生ポーカーサークル RR の代表・なおゆき。サークルのアカウントから送る)。「大学生が作ったアプリ」は応援してもらえる理由になるので必ず入れる。
- 条件は「スタートの形」と書き、**相談で調整できる**ことをそれとなく伝える。ただし調整した条件は、規約・管理者画面の設定と食い違わないよう、合意したら記録する(下の「条件を調整したとき」)。
- 返信が無ければ **3〜4日後に1回だけ**フォロー(E)。2回目は送らない。
- 1日に送る数は数十件まで(X の DM の送りすぎはスパム判定・凍結のおそれ)。

```

・最上位のプラチナプランを3ヶ月無料
・あなた専用の紹介コード

【報酬の仕組み】
① フォロワーさんが有料プランの決済画面でそのコードを入力すると、初月の支払いが30%OFFになります(Poker ART の有料会員になったことが無い方が対象)

ここに書いたのはスタートの形なので、紹介の形式や条件はご相談に合わせて調整できます。「こういう形なら」というものがあれば、気軽に教えてください。
```

## 条件を調整したとき

- いまの仕組みは全員が同じ条件(最初の3回分は80%・以降は解約まで20%・初月30%OFF)で自動計算する。率や回数を人ごとに変えた場合は、管理者画面のメモ欄に合意した条件を書き、差額は振込のときに手で調整する(人ごとの条件を仕組みに入れるなら、パートナーごとの率・回数の設定を足す)。
- 合意した条件は DM の文面で残しておく(あとで揉めないように)。

## 書かないこと

- 「必ず勝てる」「稼げる」などの断定(規約で禁止している表現。景品表示法の優良誤認にもなる)。
- 条件を DM の文面だけで約束しない。必ず規約のリンクを添える(規約を変えたら DM の文面も揃える)。
