# GTO Wizard スクショ → 数値

- `run.py <画像> <行動名をカンマ区切り> <出力.json>`：13×13 の表を読む。凡例の色は右の大きな箱から自動で取る。
- 前提の画面：Mac の GTO Wizard アプリ、窓の幅 1092px、右の行動パネルを開いた状態（縮小 1.0 のスクショ 1372×892）。表のマスの境目は `parse.py` の `XB` / `YB` に実測値で書いてある。窓の大きさが変わったら測り直す。
- 1マスの読み方：横の色の割合 = 行動の頻度。下から塗られた高さ = そのハンドがレンジに入っている割合（`weight`）。
- 弱点：レンジがとても狭い場面（5bet など）は塗りが 1〜2px で、`weight` の誤差が大きい。ハンドごとの頻度は正確。
- 原画は Mac の `~/Documents/PokerART/gtow_raw/<形式>/<スタック>/<場面>_<ポジション>.png`（リポジトリに入れない）。
