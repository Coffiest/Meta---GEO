# 解説の用語集(バリィの解説で使う言葉)

棋譜解析の解説(バリィの台詞・「詳しく見る」の本文・知識ベースのルール)は、**ここにある日本語のポーカー用語で書く**。
同じものを別の言い方で書かない(例: 「同じマークの2枚」とは書かず「スーテッド」と書く)。
新しい解説を足すときも、この表にある言い方に揃えること。表に無い用語を使うなら、先にここへ足す。

参考: [ポーカー用語集(light-three)](https://light-three.com/pokerterms/) / [ギャッパーとは(RAQ MAGAZINE)](https://raq-hiphop.com/poker-word-gapper/) / [スーテッド・ギャッパーとは](https://raq-hiphop.com/poker-word-suited-gapper/)

## ハンド(手札2枚)の分類

| 用語 | 意味・例 | 書かない言い方 |
| --- | --- | --- |
| スーテッド(s) / オフスート(o) | 同じスート / 違うスートの2枚(AKs / AKo) | 同じマーク、マーク違い |
| ポケットペア | 同じランクの2枚(22〜AA)。22〜66 はスモールポケット、77〜TT はミドルポケット | 2枚同じ数字 |
| コネクター / スーテッドコネクター | ランクが隣り合う2枚(98o / 98s) | つながったカード |
| ワンギャッパー / ツーギャッパー | 間が1つ / 2つ空いた2枚(97s / 96s)。「ツーギャッパー以上」= 3つ以上空いたものも含む | つながらない、離れたカード |
| ブロードウェイ | T〜A の2枚(KQ, AJ, QT …) | 絵札、高いカード2枚 |
| スーテッドエース(Axs) | A と小さいカードのスーテッド(A5s 〜 A2s はホイールエース) | Aと同じマークの小さいカード |
| ハイ+ロー(のオフスート) | ブロードウェイ1枚+ 9以下の1枚のオフスート(K4o, Q6o, J5o) | 大1枚+小1枚 |
| ロースーテッド | 9以下どうしのスーテッド(74s, 53s) | 低いスーテッド |
| プレミアム | QQ+ / AK | 強い手 |

## 出来た役(ボードとの関係)

| 用語 | 意味 |
| --- | --- |
| オーバーペア | ボードの最高ランクより上のポケットペア |
| トップペア / セカンドペア / ボトムペア | ボードの1番目 / 2番目 / 一番下のランクとペア |
| アンダーペア | ボードのどのランクより下のポケットペア |
| キッカー | トップペアのもう1枚。トップキッカー / グッドキッカー / ウィークキッカー |
| セット / トリップス | ポケットペア+ボード1枚 / 手札1枚+ボードのペア |
| ツーペア / ストレート / フラッシュ / フルハウス | 役の名前はそのまま |
| ナッツ | その時点で一番強い手。セカンドナッツ |
| ショーダウンバリュー | 降りずにショーダウンまで行けば勝てる見込みのある強さ |

## ドロー

| 用語 | 意味 |
| --- | --- |
| フラッシュドロー / ナッツフラッシュドロー | 同じスートが4枚(A を持つならナッツ) |
| OESD(オープンエンド) | 両側どちらでもストレートになる4枚 |
| ガットショット | 中1枚が入ればストレートになる4枚 |
| バックドア(BDFD / BDSD) | ターン・リバー2枚続けて揃えば完成 |
| コンボドロー | フラッシュドロー+ストレートドローなど、複数のドローを同時に持つ |
| 2オーバー(オーバーカード) | 手札2枚ともボードの最高ランクより上 |

## ボード

| 用語 | 意味 |
| --- | --- |
| ドライ / ウェット | ドローが少ない / 多いボード |
| モノトーン / ツートーン / レインボー | 3枚同じスート / 2枚同じスート / 全部違うスート |
| ペアボード | ボードにペアがある |
| ハイボード / ローボード | 最高ランクが T 以上 / 9 以下 |
| ブランク(ラグ) | 前のストリートから状況をほとんど変えないカード |
| スケアカード | 相手のレンジを強くするカード(フラッシュ完成、オーバーカード等) |

## アクション

| 用語 | 意味 |
| --- | --- |
| オープン(レイズ) / リンプ / アイソレート(アイソ) | 最初の参加をレイズで / コールで / リンパーへのレイズ |
| 3ベット / 4ベット / スクイーズ | オープンへのリレイズ / 3ベットへのリレイズ / オープン+コーラーがいる所への3ベット |
| コールド4ベット / コールドコール | 自分が未参加のまま4ベット / コール |
| オールイン(シャブ / ジャム) | 残りのチップを全部出す |
| オールインにコール | 相手のオールインにチップを全部出してコールする(**ベットではない**) |
| Cベット / ディレイドCベット | プリフロップのレイザーが続けて打つ / フロップを見送ってターンで打つ |
| ダブルバレル / トリプルバレル | ターン / リバーでも続けて打つ |
| ドンクベット / プローブベット | レイザーより先に打つ / レイザーが見送った次のストリートで先に打つ |
| チェックレイズ / チェックバック | チェックしてからレイズ / 最後に回ってきてチェック |
| ブロックベット / オーバーベット | 小さく打って相手の大きいベットを防ぐ / ポットより大きく打つ |
| ジオメトリックサイズ | 残りのストリートで同じ割合を打ち続けると、ちょうどリバーでオールインになるサイズ |

## 考え方

| 用語 | 意味 |
| --- | --- |
| バリュー / ブラフ / セミブラフ | 弱い手からコールを取る / 強い手を降ろす / ドローで降ろしつつ完成も狙う |
| シンバリュー | 勝っている確率がぎりぎりのバリュー |
| ブロッカー | 相手の強い手の組み合わせを減らすカードを持っていること |
| レンジアドバンテージ / ナッツアドバンテージ | レンジ全体が強い / 一番強い手を多く持てる |
| ポラライズ / マージ | 強い手とブラフに分ける / 中くらいの手まで広く打つ |
| キャップ | そのレンジに最強の手がほぼ入っていない状態 |
| IP / OOP | ポジションあり(後から行動)/ ポジションなし |
| SPR | 有効スタック ÷ ポット |
| ICM / バブル / カバー | 賞金の期待値 / 入賞直前 / 相手よりスタックが多い |
| BvB | SB と BB だけの勝負(ブラインド・バトル) |
