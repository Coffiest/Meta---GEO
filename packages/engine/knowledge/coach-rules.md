オーナーの指示(格付け):
- プリフロップ・フロップのポットコミット → 無条件で大悪手。
- ベットへのコール → オッズの式(必要勝率)と推定勝率。足りていれば最善、足りなければ乖離に応じて緩手(5% 未満)/ 悪手(15% 未満)/ 大悪手。チェックレイズでもよい場面ならそれも言う。
- BMCB → 解説して、サイズで判定(50% 以下 最善 / 80% 以下 良手 / それ以上 緩手)。
- IP のダブルバレル・トリプルバレルが 40% 以下 → 大悪手(ポラライズの解説)。OOP のシンバリュー・ドンク・ブロックベットは対象外。
- IP のリバーのシンバリュー → ブラフレイズが少ない相手・コールしすぎる相手に刺さる。サイズは IP なら 75% 以上(それ以上は何でもよい)、OOP なら 20〜33%(オーナー指定 2026-10-30)。
- OOP(SRP)のブロックベット → セミナッツ / ガチナッツを 33〜50% で打てたら絶妙手、打てなかったら緩手。ドンクベットが有効な場面で使っても絶妙手。
- リバーでベットに直面 → MDF を示す。相手のナッツ級の代表3つをブロックしてコールしたら、相手が実際にブラフだったかに関わらず絶妙手。
- リバーのブラフレイズ → ナッツ級をブロックした A ハイ / ボードとのワンペアでレイズしたら絶妙手。その候補で降りたら緩手。

## コミットとは何か

出典: https://kihara-poker.hatenablog.com/entry/2018/01/30/144658(木原直哉)

### 要点

- コミットは「たくさん入れて降りられない状態」と思われがちだが、本当の意味は「オールインされてもオッズ的にコールしないといけないくらいのチップをポットに投入した状態」。
- 例: 400-800 アンティ 100・8000 点持ちで CO から 1800 にオープン(残り 6100)。BB にオールインされたときの必要勝率は 6100 ÷ 17100 = 35.7%(KTo 対 AQs と同じくらい)。ドミネイトされていなければほぼ何でもコールできるので、事実上降りられない = コミット。
- 1800 にレイズしても、相手は 1000 足すだけで 4900 のポットに参加でき、弱い手でもコールしてフロップを見られる。リスクは 7900 全部と変わらないのだから、最初から 7900 のオールインの方が、相手に「コールしてフロップを見る」選択肢を与えない分だけ得。
- ただし、2人以上がオールインしてきた場合などは必要勝率に届かず、コミットしていても降りるのが正しいこともある。
- まとめ: 「この額を打ったらコミットするからオールイン」= 数学的にオールインと同じリスクを負うなら、メリットを最大化するためにオールインした方がいい。

## ポットコミットとは

出典: https://zero-poker.com/potcommit/(ゼロポーカー)

### 要点

- コミットした状態 = チップを入れすぎて、フォールドすると損になる状態。降りられないのではなく、割に合う勝負を自ら投げ出せない状態。
- 例1: 15bb で AKo を 12bb に 3ベット → コールされて最悪のフロップ → 3bb のオールインに 31.5bb のポットでオッズ 10.5 倍、勝率 10% でもコール。この状況を作ったのは自分。プリフロップでオールインすべきだった。
- 例2: 30bb で 10bb の 3ベット → フロップで 7bb の CB → ターンで 10bb のベット → 残り 3bb でオールインを返されてコミット。3ベットポットはポットが膨らみやすく、フロップの時点でポットと残りのスタックが同じになったら、オールインかフォールドの覚悟が必要。
- 入賞ライン(ICM・バブルファクター)が絡むと、オッズが合っても飛ばないことの価値が大きく、降りるのが正解になることもある。
- コミットする前に決断する。事前にコミットしないように立ち回る(SPR の考え方)。

## BMCB

出典: https://zero-poker.com/bmcb/(ゼロポーカー)

### 要点

- BMCB = Bet to Missed CB。プリフロップのアグレッサーがフロップで CB を打たずにチェックしたのを見て、IP のコーラーがベットすること。
- IP は相手のアクションを見てから動ける。OOP のアグレッサーより先に打つドンクベットとは全く別物。
- 例: CO オープン(KJo)→ BTN コールドコール(77)→ ドライなローボードで CO はほとんど CB を打たない(強い手もチェックに混ぜる)。チェックを見た BTN は全体で 6 割ほど BMCB を打ち、サイズはほとんど 1/3 ポット。
- 当たっている手はバリュー、当たっていなくてもコーラーのレンジはポケットペアが多いので相手のハイカードを降ろせる。
- BMCB を打たれた側は、レイズ・コール・フォールドがほぼ均等。強い手とブラフでチェックレイズ(相手のベットの約 3.5 倍)を返すのが対策。
- モノトーンボードでも、アグレッサーがそのスートを持っていないとチェックが増えるので、IP は安く相手のハイカードを降ろせる。

## MDF(最小ディフェンス頻度)

出典: https://pokeracademy.jp/glossary/mdf/(ポーカーアカデミー)

### 要点

- MDF = Minimum Defense Frequency。相手のベットに、エクスプロイトされないために最低どれくらいの頻度でディフェンス(コールかレイズ)すべきか。
- 式: ポットサイズ ÷(ポットサイズ + ベットサイズ)。例: 100 のポットに 50 のベット → 100 ÷ 150 = 66% 以上でディフェンス。
- 完璧な指標ではなく、MDF より低く / 高く守ることもある。参考値として使う。

## リバーブラフレイズについての究極のガイド

出典: https://note.com/liz3rdtp/n/nf29e745eec66(SauloCosta #19、てっぺー訳)

### 要点

- リバーのブラフレイズは非常に利益が出やすい。多くのプレイヤーはリバーのレイズを非常に強いアクションと見て、オーバーフォールドしがち。
- 決めること: (1) どのサイズを使うか (2) どのハンドをブラフに使うか (3) どの頻度でブラフするか。
- サイズ: バリューでレイズするときと同じサイズ。バリューとブラフで別のサイズを使うと、読まれて完全にエクスプロイトされる。
- 自分のレンジを常に意識する「レンジトラッキング」の習慣が大事(自分の手を真空状態でプレイしない)。
- ハンド選び: レイズに直面した相手の手は「自動的にフォールドする領域(相手のブラフ)」「ブラフキャッチャーの領域」「自動的にコールかレイズする領域(相手のバリューのトップ)」に分かれる。
  - 自動的にフォールドする領域(相手のブラフ)をブロックしないことが最も重要。
  - 自動的にコールかレイズする領域(ナッツ級)をブロックしていれば、ブラフの利益が大きくなる。
- 2つのヒューリスティクス: (1) ボードと共通のカードを持つペアを使う (2) A ハイを使う。相手はペアや A ハイでブラフすることが少ないので、自分のカードが相手のブラフと干渉しにくく、2ペアやセットなどのナッツ級はブロックできる。
- 例: K75T2 で BTN は Q7s(サードペア)・QT(セカンドペア)・ロー キッカーの Kx でブラフレイズ。Q53Q2 の BvB では 3x・2x・A ハイ(A8o〜AJo)。Q852T の 3ベットポットでは A5s・65s・54s と Tx(K8s・ATs・T9s)。Q85 の例で AhJh は相手のフォールドレンジ(Jx)をブロックするので常にフォールド、Ah4h はインディファレントで 25% ブラフジャム。
- 頻度: (1) バリューの領域が大きいほどブラフレイズを増やす (2) 似たような候補が多いほど、それぞれを低い頻度で使う。候補の数は自分のバリューの大きさと比べて判断する(バリュー 6 コンボならブラフ 3 コンボでポットサイズとちょうど釣り合う)。
