## Flop CBの基礎 (BTN vs BB)

出典: Amu「Flop CBの基礎 (BTN vs BB)」(note, 2023-06-09。有料記事。GTO Wizard Japan 公式コーチ)。
GTO Wizard 100bb(General)のソリューションを、全フロップで大きなミスをしない精度で再現できるように整理したもの。
CO vs BB にもかなりのボードで使える。

### 考え方

- まず手札を忘れて、ボード3枚だけから「レンジ全体の CB 戦略」(使うサイズ・各サイズの頻度)を決める(Step1)。
- そのあとで、その戦略を手札に振り分ける(Step2)。
- サイズの候補は 33 / 50 / 75 / 125% の4つ。

### Step1: ボードの分類(7種)とレンジの打ち方

ボードの3枚を高い順に H(ハイ)/ M(ミドル)/ L(ロー)と呼ぶ。

| 分類 | 条件 | レンジの打ち方(サイズ: 頻度) |
| --- | --- | --- |
| Class1 モノトーン | 3枚同じスート | 低頻度で安く。33%: 25% / 50%: 5% |
| Class2 トリップス | 3枚同じランク | レンジ全体で打つ(ほぼ 100%)。999 以上は 33% か 50%、888 以下は 50% か 75% |
| Class3 ペア | ペアのあるボード | 33%: 50% / 50%: 15%(実戦では 70% くらいを 33% でも大きく外さない) |
| Class4 A〜Jハイ HMSD | H が J 以上で、H と M の2枚を使うストレートドローがある | 125% が入る。強HM(AK・AQ)は 125% だけで 50%、中HM(KJ・Q9)は 33:50:75:125 = 15:10:10:15、弱HM(Q8・J7)は 15:15:15:5 |
| Class5 A〜Jハイ HMnSD | H が J 以上で、HM のストレートドローがない | K ハイのボードのように安く打つ。33%: 35% / 50%: 20% |
| Class6 T・9ハイ | H が T か 9 | 全サイズ混合。33:50:75:125 = 15:10:10:15(Class4 の中HMと同じ) |
| Class7 8ハイ以下 | H が 8 以下 | 33:50:75 = 15:15:15。コネクトなら 33%: 30% / 50%: 15% |

- **コネクト**(何らかの2枚でストレートが完成しうる。T76 は 98 で完成するのでコネクト、AJ8 は非コネクト)は最初に判定する。コネクトしていたら 125% を外し、安いベットを好み、打つ頻度を少し高めに見積もる。
- 補足(覚えられる人向け):
  - ペアボード: 2・3 ペアのボードは残り1枚が低いほど 50%・75% を多く使う。AXX は CB 頻度が少し下がる。AAX・KKX は高い。
  - Class5: HM が低いほど大きいサイズが出る(J32・J42 は 125% も、J65 は 75% が 50% と同じくらい)。Q・J ハイは全サイズ混合になりやすい。
  - Class6: M が 6〜8 あたりだと 125% が消えやすく、HM が高いと 33% が消えやすい。

### Step2: 手の振り分け

基本方針:
- 安いベットが中心のボード(Class1・3・5・7)は、レンジの CB 頻度をまず全部の手に配り、そこから手ごとに上げ下げする。
- 3サイズ以上を混ぜるボード(Class4 の mix・Class6)は、A type(レンジの頻度どおり全サイズ混合)/ B type(最大サイズ中心の超高頻度)/ C type(安いベットかチェックの超低頻度)に分けて組み立てる。

**Class1 モノトーン(例 J85)**: 基準は CB 率 30%。
- モノトーンのバリューはトップペア・グッドキッカー以上。
- 低頻度(チェックでもよい): バリューに届かないショーダウンバリューのある手(ペアになった手、ポケットペア)。
- バリューの高頻度: ナッツフラッシュ・セカンドナッツフラッシュ・セット・オーバーペア(ランクが低いほど)・トップツーペア。
- ブラフの高頻度: ナッツフラッシュドロー・セカンドナッツフラッシュドロー・ストレートドロー・ハイ+ローのスーテッド。スートに関係なくある程度打つ必要がある。
- それ以外は平均の頻度。

**Class2 トリップス**: 全部打つ。

**Class3 ペア**: まずほとんどの手を同じ頻度で打つ。そこから点数で上げ下げする。
- トリップス +3 / グッドキッカーのツーペア・セット +2 / ストレートドロー+オーバーカード +1。
- A とミドルで当たっていない −1 / ボードと同じスートのないハイカード −1。
- XXY のボードで Y の直上に近い手は +2〜+1、直下に近い手は −1。

**Class4 ポラー(強HM)**:
- バリューはトップペア・グッドキッカー以上(セット・ツーペア・キッカーが良いトップペアほど高頻度)。
- ブラフ: ボトムペア・ストレートドロー・弱いポケット・フラッシュドロー・ミドル以下の2枚・バックドアを作るオフスート・バックドアのスーテッド。上の方ほど高頻度で 125% を使う。直感より多くの手をブラフに入れる。トップだけスートの違うツートーンでは、トップペア+フラッシュドローもかなり打つ。

**Class4 mix・Class6(全サイズ混合)**:
- B type: ボトムセット・オーバーペア・トップペアのグッドキッカー(キッカーが悪いと A type 寄り)・ストレートドロー・当たっていないハイ+ロー。
- C type: トップのハイカード+ミドルのキッカー・ポケットペア・トップペアのウィークキッカー・セカンドペア。
- A type: B にも C にも入らない手。
- フラッシュドローのあるボードでは、フラッシュドローやバックドアの色を持つ手を高く評価する。

**Class5 HMnSD(例 K63)**: 基準は CB 率 55〜60%。
- セット: 超高頻度 / ツーペア: 高頻度 / トップペア: キッカーが良いほど高頻度。
- セカンド・ボトムペア: キッカーにあまり関係なく中頻度(トップキッカーは高め)。
- ポケットペア: ハイの直下ほど低頻度。
- トップのハイカード+ミドルのキッカー: 低頻度。
- そのほか: 中頻度。ハイ側にボードと同じスートを持つと高評価、ロー側は中評価、持たないと低評価。

**Class7 8ハイ以下(非コネクト)**: Class5 に準じる。
- オーバーペアが多い。直上のものほど高頻度。
- K ハイ+トップキッカー(KQ など)も低頻度に入る。

### 注意

- 均衡(GTO)を前提として持つための知識で、エクスプロイトを語る記事ではない。
- 記事にないボード(AJXr など)もある。スートの振り分けなど細かい点はこれをベースに補う。
